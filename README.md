# Кадр за кадром — PWA

Приложение на чистых HTML, CSS и JavaScript, без сборки и зависимостей.

Откройте https://BasilDaniel.github.io/30-day-challenge/. Не открывайте `index.html` через `file://`: service worker требует localhost или HTTPS.

## Установка на телефон

Опубликуйте папку на HTTPS-хостинге (например, GitHub Pages или Netlify). Откройте адрес в браузере и используйте «Установить приложение» (Android) или «Поделиться → На экран Домой» (Safari на iPhone).

## Возможности

- 30 заданий, включая расширенные дни 1 и 7.
- Раскадровки, советы по движению камеры, настройки iPhone/DJI и монтаж в iMovie.
- Отметки снятых кадров, выполненных дней, заметки и прогресс.
- Офлайн-работа после первого посещения.

Прогресс хранится только в `localStorage` текущего браузера; синхронизации между устройствами нет.
